# Nurture the Blue Flower

> To love someone is to nurture a flower.

一个不依赖框架的像素养花小游戏，可直接部署到 GitHub Pages。

播种后会出现高速划过的红蓝五角流星群。每一波红蓝会同屏出现，并从左右两个方向交错飞来。接住三颗蓝星后，可以选择使用一次咖啡或巧克力；误点红星会失去一颗已收集的蓝星，连续漏掉三颗蓝星则会让花朵成长值减少 10。页面只保留花朵成长进度条，同时适配桌面和 iPhone 竖屏。

游戏内置温柔的通关保底：播种后若连续 15 秒没有成功点中任何流星，夜空会自动放慢。这个状态会保持到本局结束，同时扩大点击范围、提高每波蓝星数量，让不熟悉动作游戏的玩家也能轻松完成花朵培育。

## 本地预览

直接打开 `index.html`，或在项目目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作

- 点击“播种”开始。
- 蓝色流星：接住后蓝星 `+1`，最多保存 `3` 颗。
- 红色流星：误点后已收集蓝星 `-1`，最低为 `0`。
- 咖啡或巧克力：都需要 `3` 颗蓝星，使用后消耗全部三颗。
- 连续漏掉 `3` 颗蓝色流星：花朵成长值 `-10`；成功接住蓝星会重置漏接计数。
- 成长达到 `100` 后，花苞会等待最后一步；“播种”按钮变成 `💋 香吻`，点击后花朵才会在满屏像素爱心中盛开。
