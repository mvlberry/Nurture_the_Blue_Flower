# 移动端结尾文字可读性设计

## 目标

解决 iPhone 竖屏下结尾文案实际只有约 7px、难以阅读的问题，同时保持像素风格和逐行出现的演出。

## 方案

只在 `max-width: 760px` 的移动端断点覆盖结尾样式。主文案使用约 15px 字号、1.7 行高和较小字距，最大宽度限制在画面内；“未完待续”提升到 10px。桌面端保持原来的紧凑像素比例。相比整体缩放结尾容器或更换字体，这种方案影响范围最小，也不会改变幕布与动画逻辑。

## 验证

在 390×844 和 375×667 视口确认主文案计算字号不小于 14px、署名字号不小于 10px、文字矩形未超出游戏屏幕，并生成移动端结尾截图做视觉检查。
